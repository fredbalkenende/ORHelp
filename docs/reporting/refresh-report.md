# Refresh Report

Use **Refresh Report** to update all tables, charts, and shapes in a PowerPoint presentation.

![Refresh report in the OfficeReports Ribbon Tab](/Resources/Images/RefreshInRibbon.png)

Use **Refresh Report** when changes affect multiple OfficeReports objects in the report.

Examples include:

- adding new data
- changing variable texts or category names
- adjusting formulas for derived banner variables
- changing report filters
- replacing the workbook with the workbook containing the next wave

### Refreshing Reports When Using Raw Data

In PowerPoint, **Refresh Report** automatically refreshes the workbook first when it is open in the **Workbook Pane**. This updates all crosstabs before the presentation is refreshed.

When the workbook is open in Excel, refresh the workbook manually before refreshing the presentation.
